# FIA 전표 메타 분석

FIA는 실제 원장에 명시적으로 연결한 전표 입력·승인 메타를 검토하는 규칙 분석이다. 외부 AI 호출이나 부정 확정 기능은 없다. 입력시각을 원장 전기일에서 추정하지 않는다.

## API

`analyze(path, context, ledger_result=None, event=None)`는 `common.result('FIA', ...)`를 반환한다. 입력은 기존 `ledger.SCHEMA`의 원장 7시트와 다음 2개 시트를 합친 확정값 XLSX다. `ledger_result`에는 현재 업무에서 실행한 실제 원장·리드 결과를 제공해야 한다.

PM 공통 `analytics_support.read_bound`가 입력 원장 통제를 재검사하고 현재 업무의 원장 7시트·리드와 정확히 대조한다. 이 연결이 실패하면 검토후보를 산출하지 않고 `분석완료=false`와 차단 결과를 남긴다. 형식·필수 메타 오류도 분석 성공으로 표시하지 않는다. 파일 형식이나 취소 자체의 오류는 공통 입력기의 `AuditError`로 전달될 수 있다.

`write_samples(target)` 또는 `fia.samples.write_samples(target)`는 22개 독립 합성 XLSX와 `cases.json`을 만들고 `{normal: Path, cases: [...]}`를 반환한다. 각 사례의 차단 여부·검토 여부·필수 코드는 고정 기대값이며 계산기에 주입하지 않는다. 기존 통합 원장은 그대로 두고 메타 또는 분석 입력의 사본만 바꾼다.

## 필요한 자료

`전표메타`는 아래 순서의 헤더를 사용하고 모든 원장 행을 회사코드+전표ID+행ID로 정확히 1:1 연결한다.

| 필드 | 의미와 처리 |
|---|---|
| 회사코드·전표ID·행ID | 원장 복합키. 중복·미등록·타회사·원장 메타 누락은 차단 |
| 입력시각 | ERP 입력 로그의 시간대 포함 ISO8601, 예 `2027-01-05T10:00:00+09:00`. 필수이며 전기일과 별개 |
| 입력자 | 로그의 입력자 식별자. 필수. 원장 작성자에서 자동 추정하지 않음 |
| 전표유형 | 수동/자동/미확인 중 명시. 누락·기타 값 차단. 미확인은 수동으로 추정하지 않음 |
| 승인상태 | 승인/대기/반려/미확인 중 명시 |
| 승인자·승인시각 | 승인 상태에는 둘 다 필수. 승인시각은 시간대 포함 ISO8601. 미확인 상태의 null은 관련 규칙 미확인 |
| 부서·원천시스템 | 제출 로그의 분류값. null 또는 `미확인`은 미확인으로 남기고 사용자나 적요로 추정하지 않음 |
| 재분류그룹 | 제출자가 명시한 재분류 그룹 ID. `해당없음`은 명시적 비대상, null 또는 `미확인`은 미확인. 적요로 그룹을 자동 추정하지 않음 |

한 전표의 모든 행에 입력·승인·유형 등 메타가 같은 형식만 지원한다. 같은 전표의 메타가 충돌하면 임의로 첫 값을 채택하지 않고 차단한다. 앞뒤 공백도 식별자 정규화로 조용히 제거하지 않는다.

`FIA설정`은 `항목`, `값` 두 열이며 다음 12개 항목을 정확히 한 번씩 입력한다.

| 항목 | 예시·정책 |
|---|---|
| 규칙버전 | `FIA-1.0` |
| 정책명 | 정책의 적용 근거를 식별할 이름 |
| 마감시각 | 결산 마감 또는 승인된 전기 제한 시각, 시간대 포함 |
| 메타추출시각 | 입력·승인 로그의 추출 시각, 시간대 포함 |
| 업무시간대 | 고정 UTC offset, 예 `+09:00`. 지역명·일광절약시간 자동 추정 없음 |
| 업무시작·업무종료 | 같은 날의 `HH:MM`. 시작 포함·종료 제외. 자정을 넘는 근무 구간 미지원 |
| 수동집중최소전표수 | 1~10,000개 전표. 행수가 아님 |
| 수동집중최소금액 | 수동전표의 차변합계 기준, 0 이상 정수 원 |
| 수동집중비율 | 1~100 정수 백분율. 같은 입력자의 전체 전표 수 대비 수동 비율 |
| 반복재분류최소횟수 | 2~10,000개의 서로 다른 전표 |
| 선승인허용 | 예/아니오. 정상 사전 승인과 잘못된 시각 순서를 구분하는 명시 정책 |

## 적용 규칙

| 규칙 | 탐지 조건 |
|---|---|
| FIA_POST_CLOSE | 입력시각이 명시된 마감시각 후이고 원장 전기일은 현재 업무 기준일 이하 |
| FIA_MANUAL_CONCENTRATION | 입력자별 수동 전표 수·차변합계·수동 비율의 세 기준을 모두 충족 |
| FIA_SELF_APPROVAL | 승인 상태에서 입력자와 승인자가 동일 |
| FIA_TIMESTAMP_ORDER | 입력·승인이 추출시각 후, 선승인 금지 정책에서 승인시각이 입력보다 빠름, 또는 승인완료가 아닌 상태에 승인시각 존재 |
| FIA_OUTSIDE_HOURS | 명시한 고정 시간대로 환산한 입력시각이 설정 구간 밖 |
| FIA_RECLASS_REPEAT | 같은 입력자·명시적 재분류그룹·차변/대변 계정집합으로 서로 다른 전표가 기준 이상 반복 |
| FIA_APPROVAL_STATUS | 명시된 수동전표의 승인상태가 대기 또는 반려 |
| FIA_METADATA_SCOPE | 부서·원천시스템이 부족하면 분류정보 미확인. 이를 위험 확정으로 표시하지 않음 |

연말 전기·익년 입력이라는 이유만으로 마감후 입력으로 판정하지 않는다. 마감 전에 정상적으로 입력한 결산 전표를 대조군으로 포함했다. 시각 비교는 시간대가 있는 절대 시각으로 하며 업무시간만 설정한 고정 offset으로 환산한다. 휴가·공휴일·개인 활동이나 고의성은 추정하지 않는다.

## 결과와 검토

- `현재원장연결`: PM 공통 연결표와 상세 근거를 보존한다.
- `검토후보`: 후보ID·규칙ID·버전·전표ID·사유·조건·원본행·메타행·후속절차·우선순위를 제공한다.
- `규칙적용`: 규칙별 검사대상·후보·미확인 수와 적용 설정을 남긴다. 미확인을 조건 불해당이나 0으로 바꾸지 않는다.
- `전표메타대사`: 원장 전기일과 입력/승인 시각·분류·복합키·실제 Excel 행 위치를 함께 제공한다.
- `입력_FIA설정`, `입력_전표메타`: 제출된 원문 값과 위치를 보존한다. 원본 파일명·SHA256은 공통 source에 남긴다.

후보의 우선순위는 검토 순서이며 확률이나 부정 점수가 아니다. 차변합계는 대상 규모로만 사용한다. 같은 전표가 여러 규칙에 나타날 수 있으므로 후보 금액을 전체 왜곡표시로 합산하지 않는다. 동일 입력자·승인자도 적법한 별도 검토가 있을 수 있다. 정상 배치·결산 사유·권한·로그와 독립 증거를 확인해야 한다.

자동 결과의 작성자·검토자·결론은 null, 수정승인과 부정확정은 false로 유지한다. 제출 메타와 정상 원장·로그는 합성 자료로서 독립된 외부 감사증거가 아니다. 실제 ERP의 추출 완전성·로그 신뢰성·승인권한이나 법정 감사기준 준수를 인증하지 않는다.

검증은 프로젝트 폴더에서 `python -m unittest test_fia -v`로 재현한다. 정상·위험·정상 유사·누락·중복·회사/기간·현재 원장 불일치, 마감과 업무시간의 경계, UTC 동등 시각, 승인 정책, 미확인과 차단을 구분하여 검사한다.

# 분석용 합성 원천자료

이 자료는 기존 정상 분석용 XLSX를 목적별로 나눈 **동일 합성 입력의 분해본**입니다. ERP·은행에서 새로 수집한 자료나 서로 독립된 감사증거가 아닙니다. 원장·ERP 메타·은행·통제·승인근거가 같은 합성 시나리오에 속합니다. 파일 이름의 “원천”은 자료 형태를 설명합니다.

- `00_분석자료요청목록.xlsx`: 모집단·필수키·날짜/시간·통제·제출형태·유의사항 19개.
- `01_GL_TB_합성원천.xlsx`: 기준 정상 원장의 설정·TB·GL·계정매핑·독립통제·감사조정·모듈연결 7시트.
- `02_ERP전표로그_합성.xlsx`: FIA 설정과 전표 메타 2시트.
- `03_은행현금_합성원천.xlsx`: 은행·계좌·배부·지급근거·변경이력 등 현금 전용 9시트.
- `04_GLA_정책.xlsx`: GLA 설정 1시트.

현재 앱의 실제 분석 입력은 **공통 원장 7시트와 해당 분석 전용 시트를 합친 하나의 XLSX**입니다. 이 분해본을 각각 앱에 입력하는 기능은 없습니다. 이미 결합된 정상 입력은 `samples/통합/통합_v1.5_GLA.xlsx`, `통합_v1.5_FIA.xlsx`, `통합_v1.5_현금분석.xlsx`입니다. 먼저 같은 원장을 현재 업무의 원장·리드에 가져와 실행한 뒤 해당 분석용 결합 파일을 선택합니다.

행·셀 값·셀 타입·행순서를 보존했습니다. 날짜와 ID가 원본에서 문자열이면 문자열 그대로 둡니다. 빈칸과 0을 바꾸지 않습니다. 자료 요청 목록의 텍스트는 Excel 수식으로 실행되지 않도록 문자열 셀로 저장합니다. 검증은 분해본 재열기 대조 및 공통+전용 시트의 전체 값·타입·행순서 재구성 비교입니다.

공통 7시트의 직접 모본은 정상 GLA 결합입력입니다. 구 v1.3 원장과 실제 값·타입·순서는 같지만, 구 파일의 감사조정 시트에는 전체 셀이 null인 서식행 1개가 있습니다. 정상 분석 입력에는 헤더만 있습니다. 이 물리행 차이와 구 파일 해시를 명세에 따로 기록했으며 기존 파일은 변경하지 않았습니다.

`manifest.json`에 분해본 파일 SHA256, 모본 XLSX SHA256, 각 시트 행수·행값 해시·물리행별 해시, 연결 대상 정상 분석용 XLSX SHA256을 보존합니다. `verification.json`은 값 변경·행 누락 0 및 모본 미변경 확인 기록입니다. 해시는 해당 파일·행의 동일성을 확인하며 자료의 진위·독립성·감사 결론을 보증하지 않습니다.

실제 자료 요청 시에는 미제출 계좌를 포함한 전체 계좌목록, ERP/은행의 독립 추출 통제, 로그 시간대, 원본 승인·계좌변경 확인자료를 추가로 확보해야 합니다. 후보는 검토 순서이며 부정 확정이 아닙니다. 수행·판단·검토·조정 승인은 별도로 남깁니다. v1.5 릴리스 게시 여부는 실제 배포 기록을 확인해야 합니다.

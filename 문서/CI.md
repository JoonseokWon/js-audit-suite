# 화면 없는 Windows CI 검증

v1.4 소스 폴더에서 다음 순서로 실행합니다. GitHub Actions의 Windows Python 3.12·3.14 환경에서 사용할 수 있습니다. `openpyxl`과 `defusedxml`만 있으면 아래 검증기는 실행되며, EXE 빌드용 패키지는 필요하지 않습니다.

```powershell
python -m pip install openpyxl==3.1.5 defusedxml==0.7.1
python -X utf8 -B -m unittest discover -p "test_*.py" -v
python -X utf8 -B tools/verify_headless_v14.py --output-dir "$env:RUNNER_TEMP/audit-headless-v14"
```

로컬에서는 마지막 출력 경로를 새 폴더로 지정합니다. 같은 결과를 덮어쓰지 않도록 새 폴더 또는 비어 있는 폴더만 허용합니다. 소스·입력 자료 폴더 자체에는 결과를 만들 수 없습니다.

```powershell
python -X utf8 -B tools/verify_headless_v14.py --output-dir "검증/headless-v14-run1"
```

검증기는 `app.py`·Tk를 import하거나 창을 만들지 않습니다. 기존 `verify.regression`·`check_book`과 실제 `Workspace.execute` API를 사용합니다. 입력 기대값은 계산 후 비교용으로만 읽으며 계산 함수에 주입하지 않습니다. 단위 테스트 개수와 파일 사례 개수는 구분합니다.

| 범위 | 파일 사례 |
|---|---:|
| 기존 엔진 55 + 통합 입력 158 | 213 |
| 계정군 9개의 독립 연습 | 33 |
| 재무제표 정상 1 + 변형 13 | 14 |
| 전체 원장을 공유하는 공통 거래 | 10 |
| 합계 | 270 |

추가로 공통 정상 업무의 12개 모듈·32개 원장 대사·리드 59계정·재무제표 비교 94개·현재 원장 연결 141행을 검사합니다. 자산 5,438,569원, 부채 5,283,551원, 자본 155,018원, 당기순손실 6,583,982원과 작은 공통 거래의 현금 130원·재고 150원·매출 280원은 고정 손계산 기대값으로 확인합니다. 허용오차 내 차이, 부호 오류, 원장 재실행 후 옛 연결 무효화, 미수행 조서 검토요청·완료 내보내기 차단도 검사합니다.

결과 폴더의 `report.json`에는 성공 여부·오류·통과한 검사 목록·270개 사례의 관찰값이 남습니다. `normal_draft.xlsx`는 실행·증거·대사·F01/R01 미검토 조서와 증적 JSON을 담은 초안입니다. 상태는 자동으로 수행·검토 완료되지 않습니다. 원장·자료 사본을 포함한 업무 폴더도 해당 출력 폴더 안에 보관합니다. 검증 전후 원본 소스·샘플 해시를 비교하여 입력 변경이 없었는지 확인합니다.

Actions에서는 검증 실패 시에도 이 출력 폴더를 CI artifact로 올리도록 `if: always()`를 적용하면 실패한 마지막 검사까지 확인할 수 있습니다. 저장소에서 v1.4 소스가 하위 폴더에 있으면 해당 경로를 job의 작업 디렉터리로 지정해야 합니다. UI·EXE 검사는 별도 Windows 검사 결과를 사용하며, 이 검증기의 통과로 창·파일선택기·깨끗한 OS 실행까지 확인했다고 주장하지 않습니다.

모든 사례는 합성 자료입니다. 계정별 독립 사례 33개를 공통 TB에 합산하지 않으며, 카탈로그 114개 표 전체 거래가 배부 검증된 것도 아닙니다. 선택 배부와 명시한 범위만 검사하고 미확인 범위를 유지합니다.

# v2.2.0 JS전자 로컬 AI 조서 시연

기존 업무와 별도의 JS전자 가상 업무에서 자료 입력, 오류 확인, 실제 로컬 AI 초안 작성과 사람의 수정·내용 승인, Excel 출력을 확인합니다. 예제의 차이는 의도한 누락이며 실제 회사의 거래가 아닙니다.

## 별도 예제를 열기

더보기의 새 JS전자 감사 시연을 선택하면 새 업무 폴더에 오류가 있는 입력, 정상 입력과 설명을 만듭니다. 기존 회사 자료를 덮어쓰지 않습니다. 원장 검사와 매출 검사 결과에서 독립 통제값, 청구 내역 및 현재 원장의 차이를 확인하세요. 정상 입력을 선택해 다시 검사하면 해결된 예외와 남은 확인사항을 구분할 수 있습니다.

차대가 맞는 전표 전체가 빠져도 차대 합계만으로는 찾을 수 없습니다. 예제에서는 별도로 받은 시산표·추출 통제와 원장 대사로 누락을 확인합니다. 청구행 누락은 주문·출고·청구·원장 연결에서 확인합니다.

## 실제 로컬 AI 초안

조서 A04를 열고 작성자 이름을 직접 입력합니다. AI 생성 근거 화면에서 원본 행·실제 계산·대사·예외와 생략 범위를 확인합니다. AI 설정에서 로컬 모델 준비 상태를 확인하고 초안 생성 버튼을 누릅니다. 준비가 안 되어 있으면 공식 실행환경과 지정 모델을 전용 폴더에 준비합니다. 실제 고객 자료를 예제에 섞지 마세요.

기본 로컬 AI는 전용 loopback 서버를 사용합니다. 키나 사용자 환경설정을 외부 AI로 자동 전환하지 않습니다. 실제 모델 응답은 근거와 인용 검사를 통과해야 저장할 수 있습니다. 실패·취소·근거 변경 시 초안·승인을 새로 기록하지 않습니다. 오류가 있다고 무조건 회계오류로 확정하거나 오류가 없다고 감사완료로 서술하지 않습니다.

원문 고정 구간은 프로그램이 제공한 원문·안전 경고이고, 그 뒤 AI 서술은 모델의 제안입니다. 수치 출처 검사에는 한계가 있습니다. 같은 숫자가 근거에 있다는 사실만으로 계산 의미·분류·실질·감사 판단이 옳은 것은 아닙니다.

## 적용·수정·내용 승인

생성된 초안은 먼저 별도로 보존됩니다. 초안 적용 후 근거를 보며 문장을 수정하고 저장하세요. 실제 수행하지 않은 조회·실사·증빙 조사나 판단을 완료한 것처럼 입력하지 않습니다. 원장·자료·설정이 바뀌면 새 검사와 새 근거의 초안이 필요합니다.

AI 내용 승인은 사람이 현재 저장 문장을 확인했다는 기록입니다. 승인자·수정·판단 범위는 직접 입력합니다. 이름은 본인인증·전자서명이 아닙니다. 별도 검토자는 수행·증거·현재 원장 대사와 필수값을 확인하며, 미충족 조건은 그대로 남습니다. 내용 승인만으로 데이터 예외가 해결되거나 전체 감사가 완료되지 않습니다.

## Excel 출력과 재확인

상단 초안 Excel 저장으로 현재 상태를 출력합니다. A04 조서의 수정 문구, 자동검사 및 원장 대사, AI 초안·근거 참조·현재 내용 승인·변경 이력을 확인하세요. 미승인·미검토 출력도 그 상태를 표시합니다. 원본·업무 DB와 같은 경로에 덮어쓰지 않습니다.

원장 재실행과 본문 수정 후에는 이전 승인 상태를 다시 확인하세요. 프로그램은 변경 전 승인과 근거를 삭제하지 않고 이전 이력으로 보존합니다.

## 검증 범위

소스와 EXE에서 실제 로컬 추론을 각각 실행하고, 수정·가상 내용 승인·Excel 저장·다시 열기·변경 무효화를 별도 검증합니다. 가상 승인 시험은 검증용 별도 업무에만 입력하며 사용자용 예제에는 넣지 않습니다. 실제 사람의 감사 판단·승인이나 실제 OpenAI 호출 검증을 수행한 것으로 보고하지 않습니다.

공개 보고서는 합성 사례·해시·모델 식별과 검사 요약만 제공합니다. 모델 가중치·원응답·원본 교육자료·DB·키·로컬 로그는 공개하지 않습니다. 기존 버전과 업무는 보존합니다.

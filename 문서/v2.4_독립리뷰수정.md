# v2.4.0 독립 리뷰 수정 안내

v2.2.0 독립 리뷰의 8개 지적사항을 v2.3.0 고정 소스의 별도 복사본에서 수정합니다. 이 단계는 코드와 회귀검증이며 새 EXE·공개 릴리스를 제공하는 단계가 아닙니다. 예전 소스·업무·리뷰 재현자료를 덮어쓰지 않습니다.

## 원본 회사와 원장

ERP 원본의 회사 열을 명시하고 원본 회사코드와 현재 업무 회사코드를 연결합니다. 원본 코드·연결 결과·파일/시트/행 위치와 해시를 남깁니다. `1`과 `01` 같은 다른 식별자를 임의로 같게 만들지 않습니다. 다른 회사 또는 혼합 회사의 행은 차단합니다.

회사 열이 없는 예전 Excel 양식은 읽을 수 있지만 **회사 미확인**입니다. 현재 회사명으로 보충하지 않습니다. 실제 원본과 회사 연결을 확인하기 전에는 현재 원장과 연결됐다고 표시하거나 새 표준 원장으로 등록할 수 없습니다. 매핑 변경은 입력 확인 해시를 바꿔 다시 확인하도록 합니다.

## AI 조서

화면에서 두 내용을 구분합니다.

1. **프로그램 근거 기록**: 회사·기간·절차와 선택한 참조의 종류·원문 상태·값·단위·해시가 일치한 구조화 항목을 프로그램이 표시한 것입니다. 실제 사람의 수행이나 회계적 결론을 만들어내지 않습니다.
2. **AI 미검증 문장 제안**: 모델이 실제 생성한 문장을 원문대로 보존합니다. 인용 ID의 존재가 문장 전체의 사실성을 입증하지 않습니다. 잘못된 회사·실사 수행·감사완료 등의 문장을 검증된 사실로 적용하지 않습니다. 조서 본문에는 자동 합치지 않으며 사람이 근거를 보고 필요한 부분을 직접 수정해 작성합니다.

구조화 항목의 종류·상태·값·단위·참조가 원자료와 다르거나 필수 예외·대사가 빠지면 초안 적용을 거부합니다. 모델 JSON을 고쳐 실제 모델이 맞게 답한 것처럼 저장하지 않습니다. 구조화 근거의 비교 통과는 원본 진위·회계 판단의 적정성 인증이 아닙니다.

이전 계약의 초안·승인·검토 이력은 보존하며 조회할 수 있습니다. 새 적용이나 내용 승인은 현재 계약으로 다시 생성해야 합니다. 사람의 내용 승인과 별도 조서 검토, 자료 변경에 따른 재검토 통제는 유지합니다. 가상 이름의 테스트 상태전이는 실제 승인으로 세지 않습니다.

## AI가 전달받은 범위

계산표 명세에는 한 행도 전달하지 않은 표와 입력용 결과표까지 전부 포함합니다. 각 표의 전체 행수, 전달한 고유 행수, 생략 행수와 사유, 전체표 해시를 기록합니다. 우선 보존한 행과 일반 발췌에 같은 행이 중복돼도 포함 행수는 한 번만 셉니다. 최종 문자 예산 때문에 참조를 제거한 뒤에도 다시 집계합니다.

작은 패킷은 열 이름과 사유 코드를 한 번 선언하는 압축 구조를 사용합니다. 화면에서는 `ai_evidence_inventory.table_rows`로 원래 항목명을 펼쳐 보여줍니다. 포함/생략 집계와 해시는 압축 전후 동일합니다. 필수 근거와 명세가 한도에 들어가지 않으면 명세를 숨기지 않고 범위를 줄이라는 오류를 표시합니다.

전체표 해시만 전달한 것은 표의 전체 내용을 모델이 읽었다는 뜻이 아닙니다. 계산 결과표의 행수는 거래 모집단 수나 감사 수행 완료율이 아닙니다.

## 저장·Excel·중단 안내

새 사람이 입력한 본문·검토기록·자료요청·계획 등의 XML 금지문자는 저장 전에 코드와 위치를 알려 수정하도록 합니다. 기존 DB와 원본 증거는 변경하지 않습니다. 기존 금지문자는 출력 사본에서 `⟦U+0001⟧`처럼 보이고 원문은 증적 JSON에 보존합니다.

긴 문장은 문자열 순서와 줄바꿈을 보존한 계속 행으로 나눕니다. Excel 행높이는 409pt 이하, 셀은 30,000 UTF-16 단위 이내로 생성합니다. 금액·수량·비율은 첫 행에만 두어 계속 행 때문에 합계가 중복되지 않게 합니다. `출력문단연결`에서 원본 행과 출력 위치를 확인할 수 있습니다. 작은 출력과 큰 원장의 쓰기 전용 출력에 같은 규칙을 적용합니다.

검사 실행 전 취소는 완료 0건의 중단입니다. 일부 실행 후 중단은 처리 건수와 나머지를 알리고 실패는 오류를 표시합니다. 검사 실행 완료와 발견사항 유무도 구분합니다.

계약 기간에 따른 귀속 참고액과 후속 송장의 귀속액이 다르면 두 값·기간·근거를 보존해 검토 항목으로 남깁니다. 프로그램이 한쪽을 정답으로 고르거나 감사조정을 승인하지 않습니다.

검증 결과는 별도 보고서에 기록합니다. 숨김 창 입력·Unicode 왕복·OOXML 구조 검사는 실제 한글 IME 키입력, 혼합 DPI 또는 실제 Excel 화면 검증을 대신하지 않습니다.

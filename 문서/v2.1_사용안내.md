# v2.1.0 실무자료와 원장 연결 감사절차

Windows에서 실행하는 회계감사 지원 프로그램입니다. 기존 계정별 검사에 ERP 자료 정리, 자산 증감, 표본 선정, 금융기관 조회, 주석 구성, 분류 검토와 원장 연결 현금흐름표를 추가했습니다. 확정된 원화 금액과 사용자가 확인한 매핑·정책 범위에서 계산과 대사를 지원합니다.

`JS-Audit-Suite-v2.1.0-windows.zip`을 풀고 `실행파일/통합 회계감사 v2.1.0.exe`를 실행하세요. 옆의 `portable-config.json`을 함께 보관하면 새 업무를 `데이터/회사별업무`에 저장합니다. 이전 실행파일과 업무 폴더는 보존하고, 새 버전에서 확인할 업무는 사본으로 먼저 검토하세요.

## 기본 진행 순서

회사와 업무를 선택하고 감사계획·중요성·적용 범위를 기록합니다. 자료를 등록한 뒤 원장 통제를 실행하고, 해당 실무절차의 입력 양식과 원본 자료를 연결합니다. 설정과 자료를 확인한 사용자가 이름·사유를 입력하고 확인해야 계산을 진행할 수 있습니다.

계산 뒤에는 원장 대사와 예외사항을 검토하고 조서의 실제 수행내용·판단·결론을 작성합니다. AI 초안을 사용한 경우에도 사용자가 근거와 문장을 수정·확인하며, 조서 검토는 별도로 진행합니다. 자료나 원장·설정이 바뀌면 다시 검사하고 확인해야 합니다. 작성자 이름 입력은 본인인증·전자서명이 아닙니다.

## 실무자료·원장

ERP 원본 Excel의 열을 전표번호·행ID·전기일·계정·금액 등 표준 필드에 연결합니다. 원본 파일의 실제 SHA256, 시트, 물리 행번호와 원래 부호를 보존합니다. 원본을 가져오는 것과 매핑을 적용하는 것은 사람의 승인이나 자료의 정확성을 뜻하지 않습니다.

원본의 음수 차변·대변은 반대편의 양수로 변환하되 취소행을 지우지 않습니다. 한 개의 부호 금액열도 명시한 규칙에 따라 변환합니다. 계정·월·부문별 총액과 순변동, 선택 전표의 전체 행을 확인할 수 있습니다. 복합분개를 임의의 일대일 상대계정으로 배부하지 않습니다.

별도로 수령한 시산표와 계정별 원본 행수·부호 합계·정규화 차대 합계·기초 및 기말 통제값이 필요합니다. 원장에서 다시 만든 통제합계는 독립된 ERP 추출 근거가 아닙니다. 차대가 맞는 전표 전체가 누락된 경우도 독립 통제와 현재 원장 행 대사로 찾습니다.

조정전·조정후·당기변동 기준과 표시부호, 원 단위를 구분해 TB와 본문·선택 주석·제조원가를 연결합니다. 승인 상태 조정은 해당 조정값에 대한 사람의 확인 기록이 있어야 반영합니다. 동일한 검증 그룹의 원가·누계액 잔차 상쇄는 명시된 그룹과 근거 범위에서만 인정하며 개별 잔차는 남깁니다.

## 계정별 추가 절차

| 모듈 | 필요한 자료와 지원 내용 | 사람이 확인할 부분 |
| --- | --- | --- |
| 유형자산증감 | 기초·기말 자산대장, 취득·처분·건설중인자산 대체, 현재 원장 행을 연결해 모집단과 증감을 대사 | 자본화·처분·대체의 실질과 증빙 |
| 감사표본선정 | 원장과 연결한 모집단, 중요성·방법·규모·선정 조건으로 선택 결과와 제외 범위를 기록 | 방법·규모·모집단의 적절성과 표본검사 결론 |
| 금융기관조회 | 기관별 대상 목록·장부 계정·회신 및 미회신 내역과 금액을 연결 | 발송·회수 통제, 회신 진위, 대체절차의 충분성 |
| 주석구성대사 | 선택 주석의 원가·누계액·순액, 차입금 등 구성요소를 원장과 연결 | 공시 누락·표시·분류와 적용 기준 |
| 분류검토 | 만기·용도·유동성·관련 증거 등 확인할 항목을 정리 | 현금성자산·유동성 등 최종 회계분류 |
| 현금흐름표연결 | 손익·감가상각 배부·실제 현금행·비현금·대체·분류정책을 현재 원장에 연결 | 현금 범위, 활동별 분류·배부·상쇄·잔차의 실질 |

계산과 표본선정은 입력된 방법의 기계적 지원입니다. 모든 표본기법이나 모든 국가의 회계·감사기준을 구현한 것으로 보지 마세요. 조회서의 파일이 있다는 사실만으로 회신의 진위나 감사증거의 충분성이 확인되는 것은 아닙니다. 분류정책을 프로그램이 대신 확정하지 않습니다.

## 현금흐름표를 확인할 때

이번 원장 연결 모듈은 현재 업무의 원장과 조서에 연결합니다. 제조원가로 배부한 상각을 판관비와 구분하고, 현금 지급·회수 행을 비현금 인식·대체와 구분해 검산합니다. 원장 계정간 현금 이체와 복합전표의 배부 근거를 확인하세요. 전체 차이가 0이어도 서로 다른 검증 그룹의 차이를 상쇄해 없애지 않습니다.

더보기의 기존 현금흐름표 독립 도구도 보존합니다. 이 도구는 별도 입력 양식과 기존 계산 계약을 사용하며 현재 업무에 자동 연결되지 않습니다. 원장 연결 모듈과 독립 도구를 구분해 사용하세요.

## 조서·변경 이력·출력

원본자료와 검사 결과, 현재 원장 검사 버전을 조서 근거에 연결합니다. 실제 수행·판단·승인·검토 기록은 사람이 입력합니다. 원장이 다시 실행되거나 입력과 정책이 바뀌면 기존 결과를 현재 결과로 표시하지 않고 재검사를 요구합니다. 계산 결과가 일치해도 감사완료·부정 부재·감사의견을 뜻하지 않습니다.

Excel 출력과 감사파일 보관은 프로그램에 기록한 자료·조서·이력 범위의 저장과 무결성 확인입니다. 감사보고서 발행이나 감사기준 준수 인증을 대신하지 않습니다. 공식 예시서식의 모든 셀을 자동 작성하는 기능도 아닙니다.

## 입력과 검증 범위

Excel은 확정값만 받습니다. 수식 캐시·하드코딩된 TRUE를 새 계산 증거로 사용하지 않으며 수식·오류 셀, 매크로·외부 연결 파일은 거절합니다. 계정코드·원본 부호·금액 단위·추출 기간을 먼저 확인하세요. 연결재무제표의 합산·내부거래 제거를 자동으로 수행했다고 해석하지 마세요.

가상 회사와 더미자료는 사용법과 오류 검출을 확인하기 위한 자료입니다. 실제 AI 모델 호출과 실제 키보드 한글 조합 입력의 신규 확인 여부, 전체 단위검사·EXE 검증 범위는 첨부한 `validation-report.json`을 따릅니다. 교육 문제집·모범답안 원본, 실제 고객 자료·업무 DB·API 키·AI 모델·검증 로그는 공개 배포에 포함하지 않습니다.

새 계산과 화면은 `onboarding/`, `desktop/onboarding/`의 작은 모듈로 나눴고 기존 엔진·DPI·한글 편집기를 보존합니다. 공개 소스와 EXE의 계산 검증은 같은 가상 사례와 확인 항목으로 비교합니다. 시간·임의 ID·SQLite 파일 자체의 바이트가 같다는 의미는 아닙니다.

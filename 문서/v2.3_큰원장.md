# 통합 회계감사 v2.3 큰 원장

원장·리드의 10,000행 제한을 제거했습니다. 총계정원장 시트는 Excel 데이터 행 한도인 1,048,575행까지 읽으며 입력 파일은 256MB, 압축해제 합계는 1GB 이내입니다. 행을 자르거나 원장을 임의 분할하지 않습니다. 실제 가능한 크기는 메모리·파일 구조에 따라 달라집니다.

1. Windows ZIP을 모두 풀고 실행파일/통합 회계감사 v2.3.0.exe를 실행합니다. portable-config.json과 폴더 구조를 함께 보관합니다.
2. 기존 업무를 명시적으로 열거나 새 업무를 만듭니다. 기존 버전·원본·업무를 덮어쓰지 않습니다.
3. 원장·리드에서 7시트 원장을 등록하고 검사를 실행합니다. 형식과 계정코드·전표ID·행ID는 기존 규격 그대로입니다.
4. 원본 행 수, 독립 통제, 차대변, 시산표·리드와 검토후보를 확인합니다. 화면은 200행씩 조회하며 첫 페이지와 마지막 페이지까지 전체 행을 보존합니다.
5. Excel 출력은 필터와 무관하게 전체 결과를 저장합니다. 큰 출력은 순차 저장하며 증적JSON에 전체 내용을 보존합니다. 출력의 긴 요약 셀은 기존처럼 JSON 참조를 표시합니다. 대용량 출력에서 조서 내부 하이퍼링크는 생략합니다.

GLA·FIA·현금분석의 공통 총계정원장도 같은 한도를 사용합니다. ERP 변환의 원본 행도 확대했습니다. 다른 계산 모듈과 보조표의 기존 행 제한은 유지합니다. 원본 등록·업무 보관의 파일 크기 한도도 일치시켰습니다. 독립 통제·중복·전표 차대·기간·원본 해시·이력 무결성은 계속 검사합니다.

회계데이터 표준화 v0.5.1 이상의 큰 원장 내보내기를 함께 사용합니다. 표준화 앱의 업무당 250,000행 한도는 유지되며 이 원장을 한 파일로 그대로 넘길 수 있습니다. v2.2 이하에는 10,000행 제한이 남아 있으므로 새 EXE를 사용하세요.

확인: 250,000행·125,000전표의 합성 원장을 실제 소스와 EXE에서 등록·계산·저장·재열기·Excel 출력하고, 저장 Excel의 행 수·금액·앞자리 0과 화면 첫/마지막 페이지를 검사합니다. 기존 1,096개 회귀 검사와 추가 대용량 검사도 실행합니다. 실제 업무·통제 진위·사람의 감사 판단·승인을 시험으로 만들어 완료 처리하지 않습니다. 로컬 AI 모델은 변경하지 않았으며 이번 버전에서 실제 모델 추론을 다시 수행하지 않았습니다.

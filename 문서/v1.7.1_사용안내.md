# v1.7.1 — 조서 초안 작성과 화면 배율 안내

이 버전은 조서 작성 위치를 쉽게 찾고 화면의 글자·배율을 조절하도록 보완한다. 계산 정책·회사별 합성자료·업무 저장 계약은 1.7 그대로다. 기존 v1.7 업무·자료·조서·작업 이력을 새 연습으로 초기화하지 않고 이어서 사용한다. v1.7.0 EXE·공개 릴리스와 검증 기록은 별도로 보존한다.

## 1. 감사 조서 초안은 어디서 작성하나

**회사를 선택한 뒤 상단 조서초안 작성을 누른다.** **조서초안·작성** 탭을 눌러도 같은 화면이다. v1.7.0의 **절차·조서** 탭을 찾기 쉽게 이름을 바꿨다. 왼쪽 목록에서 계정/절차를 선택하면 오른쪽에 조서 입력항목이 열린다.

좁은 창·큰 배율에서는 보조 버튼을 **기타 기능 ▾** 메뉴로 모은다. 새 업무·업무 열기·계정별 증빙연습·로우데이터·자료 복사·검토완료본은 이 메뉴에서 선택한다. **조서초안 작성·초안 Excel 내보내기·화면 배율**은 상단에 남는다. 탭 제목이 일부 가려지면 **기타 기능 → 화면 이동**에서 자료·검사, 원장·리드, 결과 상세, 검토후보, 조서초안·작성, 증거·검토의견, 자료요청, 작업 이력의 8개 화면으로 이동한다.

| 대상 | 조서 ID |
| --- | --- |
| 금융상품 | A02 |
| 매출 | A04 |
| 감가상각 | A12 |
| 리스 | A15 |
| 대손충당금 | A07 |
| 재고평가 | A11 |
| 종업원급여 | A16 |
| 미기록부채·비용이연 | A08·A09 |
| 원천증빙·거래배부 | R01 |
| 재무제표·본문·주석 | F01 |
| GLA·FIA·현금분석 | G01·I01·H01 |

모회사 JS는 업종 없는 현금·투자주식·자본의 축소 별도 원장과 수동 계획을 가진다. 모회사에 자회사 매출·재고·급여의 모든 조서를 자동 생성·수행한 것으로 해석하지 않는다. 투자취득·투자평가·연결계산은 미검사다.

## 2. 초안에 들어 있는 내용과 직접 작성할 내용

| 항목 | 사용하는 방법 |
| --- | --- |
| 목적·위험·계획 | 해당 절차의 출발점으로 읽고 실제 업무에 맞게 검토 |
| 모집단·범위·계산근거 | 연결된 입력·실행·TB 대사와 정책을 확인하고 실제 선정범위를 구체화 |
| 작성자·실제 수행일 | 실제 작성/수행 정보를 입력 |
| 실제 수행내용·근거·예외 조사 | 무슨 원문을 어디까지 확인했고 차이를 어떻게 조사했는지 직접 기록 |
| 판단·결론·추가절차 | 확인 결과와 남은 한계·추가 자료·후속조치를 직접 기록 |
| 연결 증거 | 해당 계산 입력과 현재 원장·받은 원문 등 실제 근거 사본 선택 |
| 검토자·검토내용 | 별도 검토 단계에서 기록. 이름 입력은 인증된 전자서명이 아님 |

목적·범위·계산근거가 초안에 있다는 사실은 실제 감사 수행을 완료했다는 뜻이 아니다. 프로그램이 실제 수행내용·판단·결론·검토 승인을 대신 작성하거나 완료하지 않는다. 재고 A11과 급여 A16은 별도 입력·계산·조서다.

조서 오른쪽 입력영역에 세로 스크롤이 있다. 아래로 이동하면 연결 증거·검토 입력을 확인할 수 있다. 저장·검토요청 버튼은 오른쪽 하단에 두어 입력영역 스크롤과 구분한다. 폭이 충분하면 하단의 초안 출력 버튼도 보이며, 좁은 창에서는 하단 출력을 숨기고 상단 **초안 Excel 내보내기**를 유지한다. 글자를 크게 한 상태에서도 아래 항목을 스크롤해 사용한다.

## 3. 업무 저장과 Excel 출력은 다른 단계

1. 조서를 작성하고 **조서 저장·개정**을 누른다. 현재 업무 DB에 내용과 근거·자료 버전이 저장되고 개정 이력이 남는다.
2. 상단 **초안 Excel 내보내기**를 누르고 파일 위치를 정한다. 조서·계산표·원장 연결·증거등록부·요청·변경이력 등이 포함된 XLSX 초안을 만든다.
3. **초안 Excel 내보내기**는 v1.7.0의 **검토중 저장**에 대응하는 이름이다. 상단에서 사용할 수 있고 폭이 충분할 때는 조서 화면 하단에도 표시된다. 검토를 완료한 선택조서의 출력은 별도 **검토완료본**의 조건을 따른다. 좁은 창에서는 **기타 기능 → 검토완료본**에서 찾는다.

저장 전 타이핑만 한 내용은 저장 이력이 아니다. Excel은 출력 시점의 정적 사본이며, 이후 입력·계산·조서를 바꿔도 자동 갱신되지 않는다. 필요한 경우 다시 저장하고 새로 출력한다.

자료가 바뀌거나 조서를 개정하면 이전 검토를 다시 확인해야 한다. 검토완료본은 필수 수행·판단·증거·현재 원장 연결·자료요청·검토의견·필수조서 상태 등을 검사하며, 전체 감사 완료나 감사의견 발행을 뜻하지 않는다.

## 4. 화면이 작거나 흐릿하게 보일 때

v1.7.1은 Windows 시스템 DPI 인식, 일반·본문 11pt와 작은 글자 10pt의 공통 글꼴, 화면 배율을 보완한다. 화면 해상도나 Windows 설정을 바꾸는 기능이 아니라 앱이 글자·표를 그리는 크기를 조정한다.

상단 **화면 배율**에서 90%·100%·110%·125%·150%·175%를 선택할 수 있다. 100%는 현재 Windows DPI에 따른 기본 크기이고 앱 배율이 여기에 추가된다. Ctrl + / −는 단계별 확대·축소, Ctrl + 0은 100% 복귀다. 조서 아래 항목은 오른쪽 스크롤로 이동한다. 화면 배율은 계산값·회사의 자료·조서 내용·Excel 금액을 바꾸지 않는다.

창 크기와 화면 배율은 별개다. 창을 최대화해 표와 조서 영역을 넓게 사용하고, 배율로 글자·표 크기를 조절한다. 화면 배율을 올리면 같은 창 안에 보이는 행과 문장이 줄어들 수 있다.

Windows 화면 배율·모니터 구성·글꼴과 실제 PC 환경에 따라 표시 결과는 달라질 수 있다. 서로 다른 DPI의 모니터로 이동하거나 Windows 배율을 바꿨다면 대상 모니터에서 앱을 다시 실행하는 방법을 사용한다. 모든 혼합 모니터 이동을 자동 최적화한다고 보장하지 않는다. 이 버전의 실제 소스 창·EXE 검사 범위는 해당 배포의 검증 기록을 따른다.

## 5. 계산·자료·기록은 기존 v1.7과 같은 범위

기본 사용자 보관 위치는 `%LOCALAPPDATA%\JSAudit\sector-demos\v1.7`을 유지한다. 버전 이름이 v1.7.1이라고 보관 위치를 임의로 바꾸거나 기존 업무를 새 연습으로 덮어쓰지 않는다.

내장 합성자료, 모회사/자회사 범위, 원장·계정 계산·원천 연결, 자료요청·조서의 로컬 이력 계약은 유지한다. 조서초안 작성 버튼은 기존 작성 화면으로 가는 바로가기이며 별도 AI 추론이나 외부 자료 전송 기능이 아니다.

계산·원천·미확인 범위·백업의 상세는 [v1.7 사용안내](v1.7_사용안내.md), 기능별 원리는 [기능별 작동 설명](기능별_작동설명_노션원고.md)을 확인한다. 화면 설명은 이 v1.7.1 문서를 우선한다.

현재 버전의 배포 상태는 [공개 저장소의 릴리스](https://github.com/JoonseokWon/js-audit-suite/releases), 원격 검사는 [Actions](https://github.com/JoonseokWon/js-audit-suite/actions)에서 확인한다. 이 안내 자체는 EXE 빌드·실행·게시 완료 증거가 아니다.

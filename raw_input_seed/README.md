# 현재 통합업무용 원천 입력

`testdata/raw_source_baseline/`의 원본 16권을 유지하면서 원장·리드 1권만 `samples/통합/통합_v1.3_원장_리드.xlsx`와 동일한 바이트로 교체했다. 나머지 15권은 baseline 원문 그대로다. spec의 해당 book·dataset 헤더와 행, 기말잔액 참고값도 교체한 실제 시트에서 다시 읽었다.

`정상원천증빙.auditpack`은 이 seed로 만든 원천팩이다. 114표·12개 선택 모집단·32개 거래 배부를 포함한다. 선택 범위 밖 자료의 연결이나 전체 회사 모집단의 완전성을 확정하는 의미는 아니다. 미기록부채·비용이연 모듈의 입력은 기존 10개 모듈에서 별도로 등록한다.

재현: 프로젝트 폴더에서 `python tools/prepare_raw_seed.py --build-pack`. 원장·리드의 원본/교체본 SHA256, 보존한 다른 파일의 SHA256, 패키지 왕복 결과는 `preparation.json`에 기록한다. 원천 소스폴더의 파일은 수정하지 않는다.

모든 자료는 동일 프로젝트에서 만든 합성 자료다. 원천자료↔현재업무 원장의 대사 기능을 시험하며 실제 증빙의 진위 또는 독립성을 입증하지 않는다.

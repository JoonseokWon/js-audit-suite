# 차입·세금 담당 인계

이 폴더는 계정 워커의 초기 담당 설정과 합성 시험이다. 신규 `DEBT-` JSON은 기존 통합 EXE 및 포트폴리오 EXE에 연결되지 않았다. 회사 SYNTH01의 별도 2026년 KRW 자료만 다룬다. 세율·세법·유동성 분류·DTA 실현가능성은 판정하지 않았다.

## 기존 자료 재사용

`manifest.json`의 `existing_sources`에 기존 `../../../2026-10-23/spec.json`의 12개 자료와 실제 XLSX 파일·시트·범위를 색인했다. 검증기는 표준 라이브러리로 XLSX를 읽어 머리글과 전 행을 해당 카탈로그와 비교한다. CSV 파일명으로 자료를 선택하지 않는다. 원본은 수정하지 않는다.

대조 중 확인한 표현 차이는 그대로 보고한다. D007의 G2/G3는 XLSX 원문 타임스탬프 앞에 작은따옴표가 있어 카탈로그와 비교할 때만 해당 두 셀을 명시적으로 해석한다. 검증 결과에는 양쪽 원문을 남긴다. D057의 2행은 서식만 있고 모든 값이 null인 빈 행으로, 감사조정 0건과 구분해서 기록한다.

- D013 차입_조건과 D014 약정_조건: LN01 계약·이자·담보·약정 검토의 출발점.
- D012 조회_통제대장: 차입 대상 CONF03은 **미수행·미회신인 합성 예상값**이다. 실제 금융조회 증거로 표시하지 않는다.
- D042~D044: 일시적차이·세무조정·당기세액 가정. 20%는 더미의 가정이며 한국 법인세율 추천이 아니다.
- D007: IPE 추출조건과 미완료 검증 기록. 실제 독립 추출 통제는 별도 필요하다.
- D054~D058: 시산표·총계정원장·매핑·감사조정·모듈연결. 기존 J-LOAN/J-INT/J-DTL의 조서 교차참조 후보다.

기존 LN01은 2026-01-02 실행이지만 **첫해 고정이자 50,000원 약정**이라는 원천 조건이다. 이를 연간 일할 단리라고 바꾸지 않았다. 이번 DEBT-LN01은 전기부터 원금 2,000,000원이 존재하며 2026-01-01~12-31의 양 끝 포함 ACT/365 고정 단리라는 별도 사례다. 값이 같아도 기존 거래와 결합하지 않는다.

## 합성 시험 범위

1. DEBT-01 정상: 기초원금 2,000,000원, 당기 실행·상환·비현금변동 0원, 연 250bp, 365일. 이자 50,000원, 현금지급 -30,000원, 미지급 20,000원. 원장 부채는 각각 -2,000,000원 및 -20,000원이다.
2. DEBT-02 오류: 이자비용을 30,000원만 기표하고 미지급을 0원으로 기록. 이자비용과 미지급 대사에서 각각 -20,000원 차이를 찾는다. 동일 미계상 원인의 양면이므로 차이를 합산하여 왜곡금액 40,000원으로 표시하면 안 된다.
3. DEBT-03 자료누락: 차입계약이 없다. 이율·기간을 다른 사례에서 가져오지 않고 INPUT_BLOCKED로 종료한다.

필수 자료는 계약, 기초원금·미지급 명세, 명시적인 원금변동 명세, 이자 지급 자료, 원장 요약 5종이다. 계약·지급자료의 존재는 실제 증빙 진위나 충분성을 뜻하지 않는다. `review_requests`는 담보·약정·조회 검토가 아직 남았음을 보존한다. 작성자·검토자·결론은 null이다.

## 실행과 검증

이 폴더에서 `python -B verify_fixtures.py`를 실행한다. 표준 라이브러리만 사용하고 원천 파일 및 EXE를 수정하지 않는다. stdout JSON을 PM 검증 결과에 수집할 수 있다.

2026-10-23 Python 3.12.14 실행 결과 PASS: 3개 사례의 고정 기대 결과, 계산 검사 9개, 입력 차단 통제 12개, 기존 카탈로그와 XLSX 자료 12개를 대조했다. 입력 통제는 null 이율, boolean 금액, null 지급액, 다른 회사, 다른 통화, 다른 기간, 부채 부호 역전, 수수료, 원금변동, 원 단위 미만 계산, 중복 문서, 지급문서 누락을 다룬다. 출력은 원장 원본 부호 값·정확한 JSON 위치·계산값·차이·후속 검토와 동일 예외 원인 ID를 보존한다. 모든 조서 검토 상태는 미검토다.

`manifest.json`의 DEBT-PBC01~05는 다음 조서의 실제 요청자료를 정리한다.

| DEBT-WP02 이자·미지급 | 약정 이자율·변경 이력·일수기준·수수료·지급명세·은행거래·후속 지급. 지급의 원금/이자/수수료 배분 필요 |
| DEBT-WP03 약정·담보·분류 | 약정 측정일·산식·준수 근거·면제/유예 문서의 효력일·담보/보증·독립 조회 통제. 기준일 현재 권리와 공시 판단은 감사인 검토 |

## 기준 참고 범위

2026-10-23 확인한 IFRS Foundation의 공개 개요만 요청자료 범위의 근거로 사용했다. 국내 채택 기준의 전체 문구나 세법 검토를 수행한 것이 아니다.

- [IAS 12 Income Taxes](https://www.ifrs.org/issued-standards/list-of-standards/ias-12-income-taxes/): 당기세금과 장부가·세무기준액의 일시적차이 및 조건부 DTA 인식이라는 자료 범위를 참고했다. 가정세율을 실제 적용세율로 사용하지 않는다.
- [IAS 1 Presentation of Financial Statements](https://www.ifrs.org/issued-standards/list-of-standards/ias-1-presentation-of-financial-statements/): 차입 약정과 결제 연기 권리에 관련된 분류·공시 판단이 필요하다는 점을 참고했다. 임계값의 단순 비교로 유동/비유동을 확정하지 않는다.
- [IFRS 9 Financial Instruments](https://www.ifrs.org/issued-standards/list-of-standards/ifrs-9-financial-instruments/): 계약과 금융부채 인식·측정 및 거래원가 검토 범위를 참고했다. 이번 단리 시험은 유효이자율, 수수료 상각, 조건변경·제거 계산을 구현하지 않는다.

## PM 후속 연결 과제

PM은 기존 거래와 신규 독립 사례를 분리한 상태로 문서·계정 연결표를 검토해야 한다. 현금 워커와 차입 원금·이자 지급의 배분, 유형자산 워커와 세무기준액/일시적차이의 원천, 재무제표 워커와 차입·담보·약정·법인세 주석을 연결한다. IPE 완전성, 전표/행 ID·금액·날짜 검증 및 승인된 조정의 리드스케줄 반영을 끝내야 EXE 편입할 수 있다.

이번 검증은 독립 원천 데이터로 사실관계를 입증한 감사가 아니다. 같은 합성 거래를 맞게 연결하고 계산 오류·입력 누락을 구별하는 시험이다. 최종 회계 판단, 수정분개 승인과 전기, 작성자·검토자와 결론은 사람의 검토 단계로 남는다.

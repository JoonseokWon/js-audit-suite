# 자본·특수관계자·공시/종결 워커 인계

이 폴더는 공통 규격 `pm-raw-1`에 따른 독립 합성 자료의 초기 설계다. 회사는 SYNTH01, 2026년, KRW, 별도 재무제표다. **기존 EXE에 연결하지 않았고, 기존 원장·TB에 합산하지 않는다.**

## 산출물과 범위

- `manifest.json`: 경영진 주장, 기존 자료 9개 위치와 원본 파일 해시, 추가 요청자료, 연결키, 자동화 후보, 감사인 판단, 조서 초안 필드를 담았다.
- `fixtures.json`: 현금 보통주 증자와 관계자 대여금의 정상/오류/자료 누락 대안 사례 3개다. 사례 사이의 거래·증빙 번호는 동일 거래의 서로 다른 버전이다. 서로 합산하거나 섞지 않는다.
- `verify_fixtures.py`: 표준 라이브러리 검증기다. 11개 검사 × 3개 사례의 고정 기대값 132개와 비정상 입력 통제 5개를 확인한다. 기존 자료는 카탈로그 ID·행수, 실제 XLSX 시트 존재, 파일 해시까지 확인하며 XLSX의 개별 셀 값 재계산이나 PDF 내용을 검증하지 않는다.

추가 요청자료는 주주/자본변동, 이사회·주총 의사록, 배당·증자 입금·등기, 특수관계자, 약정·소송, 후속사건, 계속기업 평가·경영자확인·종결로 나눴다. 이 중 이번 계산 프로토타입은 증자와 관계자 잔액 대사만 포함한다. 다른 영역은 자료요청·판단 목록이다.

## 실행과 검증

이 폴더에서 다음과 같이 실행한다. 외부 패키지 설치가 필요 없다.

```powershell
python -X utf8 -B verify_fixtures.py
```

2026-10-23 Python 3.12.14에서 실행했고 종료코드 0, 결과 `PASS`였다.

| 사례 | 실제 검사 결과 | 고정 기대 결과 |
|---|---|---|
| EQUITY-CASE01 | 11개 PASS | 기초 자본금 6,000,000 + 증자 액면 1,000,000 = 기말 7,000,000원. 주식발행초과금 400,000원. 승인 발행액과 합성 입금 1,400,000원 일치. 관계자 잔액과 주석 100,000원 일치 |
| EQUITY-CASE02 | 9개 PASS, 2개 EXCEPTION | 합성 입금 1,300,000원으로 승인액 대비 -100,000원. 관계자 주석 95,000원으로 명세 대비 -5,000원. 자본 산식이 일치해도 두 차이를 남김 |
| EQUITY-CASE03 | 6개 PASS, 5개 INPUT_BLOCKED | 의사록·관계자 목록 누락 및 그 자료에 의존하는 승인 조건·입금·관계자 식별 검사 차단. 실제 값·차이는 null로 남김 |

검증 합계는 **독립 사례 3개, 검사 33개, 고정 값 비교 132개, 비정상 입력 거부 5개, 기존 자료 위치 9개**다. 사례에서 발견한 예외를 수정했다는 뜻이 아니라, 의도한 차이/누락을 기대한 상태로 검출했다는 뜻이다. 비정상 입력 통제는 금액 null, 금액 bool, 증빙ID 중복, 통화 문맥 불일치, 다른 거래 증빙의 오연결을 거부한다.

## 판단과 근거의 구분

합성 통제 일치는 실제 승인·납입·등기의 진위나 법적 효력, 관계자 전체 완전성, 소송·계속기업 결론을 의미하지 않는다. 이 프로토타입은 의결기관 권한, 정족수, 적법한 배당, 세율, 법률의견을 판정하지 않는다. 작성자·검토자·결론은 null이며 승인·전기 상태는 false다.

- [IFRS Foundation IAS 24 공개 개요](https://www.ifrs.org/issued-standards/list-of-standards/ias-24-related-party-disclosures/): 관계의 성격, 거래와 미결제 잔액·약정, 주요 경영진 보상 자료를 요청하는 범위의 근거다. 제공 목록에 있는 거래처를 찾는 검사만으로 누락 관계자의 완전성이 입증되지 않는다.
- [IFRS Foundation IAS 10 공개 개요](https://www.ifrs.org/issued-standards/list-of-standards/ias-10-events-after-the-reporting-period/): 보고기간말과 발행승인일 사이 사건의 조정·비조정 구분을 후속 검토 항목으로 둔다. 이번 사례는 그 분류를 계산하거나 승인하지 않는다.
- [XRB ISA (NZ) 550](https://standards.xrb.govt.nz/standards-navigator/isa-nz-550/), 13–15·23–24·28: 관계자 문의 외에도 의사록·조회 등의 추가 정보, 주요 거래의 계약·승인 및 문서화 검토를 설계하는 공개 참고다.
- [XRB ISA (NZ) 580](https://standards.xrb.govt.nz/standards-navigator/isa-nz-580/), 4: 경영자 서면진술만으로 충분하고 적합한 증거를 확보했다고 처리하지 않는다.

위 출처는 2026-10-23 확인했다. XRB 자료는 뉴질랜드 공표본이다. 국내 기준의 최신 적용판·회사 법률·구체적 사안은 담당 감사인이 확인해야 하며 이 산출물은 한국 회계·감사기준 준수 인증이 아니다. 약정·소송·계속기업의 실제 결론에 필요한 별도 기준/절차 전체를 조사·구현했다는 표시도 하지 않는다.

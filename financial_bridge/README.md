# 재무제표·주석 통합 어댑터

`analyze(path, context, ledger_result=None, event=None)`는 현재 업무의 실제 원장 입력표를 다시 검사하고 보관된 리드·통제표와 비교한 후, 조정전 TB를 재무제표 본문 및 선택 주석과 대사합니다. 별도 포트폴리오 CSV나 financial.json이 주장한 TB 금액을 원장처럼 사용하지 않습니다. 원장 통제 차단, 입력표 없음, 오래된 리드, 회사·기간 오류는 모든 재무제표 비교를 차단합니다.

입력 구조·단위·필수 매핑·합계 그래프·주석 연결 검증에는 `vendor/financial.py`를 원문 그대로 재사용합니다. `vendor/common.py`는 현재 통합 앱 common으로 연결하는 import 어댑터입니다. 원본 SHA와 출처·권리 상태는 PROVENANCE.json에 있습니다.

표: 재무제표대사, TB본문매핑, 원장리드연결, 원천위치, 입력_각 JSON 구분. 각 비교·계정 매핑에 원본 위치를 기록하며, 조서에 사용할 상태는 항상 미검토 초안입니다. 비영 차이는 허용오차 안이어도 예외로 남깁니다. 승인조정이 있는 경우 조정전 기준이라는 검토 이슈를 남기고 조정후 금액을 사용하지 않습니다. 입력이 조정후 기준이라고 선언하면 차단합니다.

`build_sample(target, ledger_result)`는 기존 v1.3 합성 계정표에 한해 정상 financial.json과 financial_cases/ 13개 변형 및 기대 결과를 만듭니다. 실제 사용자 계정은 추정 분류하지 않습니다. PM은 UI에서 정상 입력을 보여주고 오류 사례를 별도로 가져올 수 있습니다.

제한: KRW 별도 업무·미마감 PL·조정전 TB·BS/PL 및 선택 주석만 지원합니다. 원장 양식에 연결구분이 없으므로 별도 분류를 ERP에서 독립 확인했다고 주장하지 않습니다. PDF/OCR/XBRL, 현금흐름표·자본변동표 본문, 모든 공시 완전성, 실제 감사 결론과 자동 전기는 포함하지 않습니다. 동일 합성 시나리오의 자료를 독립 외부 증거라고 주장하지 않습니다.

권한과 역할: 회계 요구사항·검증은 사용자, 구현·자동 테스트 실행은 AI 보조입니다. 사용자 수동 검증 또는 실무 기준 준수 확인을 대신하지 않습니다.

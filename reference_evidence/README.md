# 참고용 합성 증빙과 자료요청 목록

기존 `통합감사 원천자료/2026-10-23`의 요청목록과 21쪽 합성 PDF를 원문 그대로 보존한 참고자료다. 인사·계약·구입·출고·입고·자금·토지·채권조회 등 증빙 작성 형태와 아직 자동화하지 않은 절차의 필요자료를 살펴볼 수 있다.

현재 v1.4의 공통 원장 기준 입력은 `raw_input_seed/`와 `samples/통합/`이다. 이 참고 PDF·요청목록은 v1.4의 현재 원장과 독립적으로 대사한 모집단이 아니며 `.auditpack` 114표 계산에 포함하지 않는다. 이전 원천자료의 거래·기간·금액은 다를 수 있으므로 합산하지 않는다. PDF/OCR 자동 추출은 구현되어 있지 않다. 실제로 검토한 참고자료는 업무의 증거에 등록하고 수동 조서에 검사 범위를 남긴다.

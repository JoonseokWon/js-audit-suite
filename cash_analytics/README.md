# 현금분석 · v1.5 합성자료 데모

현재 업무의 조정전 원장과 입력 원장 7개 시트를 재검사·대조한 뒤 명시된 현금계정의 모든 GL행을 제출 은행자료에 연결한다. 은행자료나 계좌목록이 회사 전체를 포괄한다는 주장은 하지 않는다. 완전 미제출 계좌는 독립 계좌목록·조회·추출 조건을 추가로 확인해야 한다.

## API

`analyze(path, context, ledger_result=None, event=None)`는 `common.result('현금분석', ...)`를 반환한다. 현재 업무의 정상 원장 결과가 필수다. 누락·차단·다른 회사/기간·변경된 원장이면 위험 검사를 수행하지 않는다. 입력은 기존 `ledger.SCHEMA` 7개 시트와 `cash_analytics.SCHEMA`의 전용 시트를 모두 포함한 확정값 XLSX다.

`write_samples(target)`는 입력·기대 결과 `cases.json`과 `{normal: Path, cases: [...]}`를 반환한다. 별도 자금이체 사례의 `current_ledger`는 7개 공통 시트만 있는 동반 원장이다. 해당 사례는 그 원장을 가져온 별도 업무에서 실행한다. 나머지 정상·위험 메타 사례는 기존 v1.3 정상 원장과 동일하다.

## 입력 자료와 검사

| 시트 | 목적 |
|---|---|
| 분석설정 | 대상 계정과 반복·변경 검색일수, 집중 최소 건수·금액비율을 명시 |
| 현금계좌 | 회사·계좌·현재 GL계정·KRW 및 제출 은행 기초/기말잔액 |
| 은행거래 | 입금·출금 별도 원 단위 정수, 날짜, 거래처·상대계좌·지급근거·유형 |
| 은행독립통제 | 계좌별 기간·행수·총입출금·추출 근거/시각/작성자. 무거래도 0 명시 |
| 현금원장선택 | 회사+전표ID+행ID로 명시 대상계정 GL행을 빠짐없이 한 번씩 선택 |
| 현금배부 | 은행거래와 원장행의 부호 보존 정수원 배부. 다대다와 부분배부 허용 |
| 거래처계좌 | 거래처·상대계좌·소유구분·근거. 실제 직원 개인정보 없음 |
| 지급근거 | 거래처·승인총액·KRW·일회/분할/정기/자금이체 및 근거 |
| 계좌변경 | 거래처의 이전/신규 계좌·효력일·승인일·근거 |

입출금 동시 양수·음수·공란·bool 금액, 중복 거래/배부/원장선택, 고아 참조, 다른 계좌 간 배부, 반대 부호·과배부는 차단한다. 금액이 같다는 이유로 임의로 매칭하지 않는다. 은행/장부 각각의 미배부·부분배부 잔여를 남기며 1원도 숨기지 않는다. 은행 기초+입금−출금=기말과 독립 행수·총입출금은 차단 통제다. 은행과 TB 기초·기말 차이는 시차 등을 확인할 검토 예외다.

명시 배부의 은행행과 선택 원장행에 적힌 거래처·상대계좌·지급근거·거래구분도 대조한다. 양쪽 명시값이 모순되면 금액이 같아도 차단하며, 누락은 거래근거 대조 미확인으로 기록한다. 합법 합산지급은 같은 지급배치 메타를 각 선택행에 명시하고, 분할지급은 같은 지급근거와 유형을 양쪽에 명시해야 한다. 분석기가 모순된 입력을 자동으로 고치지 않는다.

## 검토 규칙

- 동일 근거·상대계좌·출금액이 검색기간에 반복된 `일회` 지급은 검토 후보다. 서로 다른 송장 및 승인총액 이내의 명시적 정기·분할 지급은 대조군으로 남긴다. 승인총액을 초과한 제출 지급도 별도 후보다.
- 확인 가능한 외부 지급 모집단에서 상대계좌의 지급 건수와 금액 비율을 함께 검사한다. 자금이체와 소유 미확인 건은 분모에서 제외하고 범위와 미확인 사유를 기록한다. 주요 공급처 등 합법적인 집중도 있을 수 있다.
- 제출된 계좌변경 이력의 신규계좌에 효력일부터 설정 일수 내 지급이 있으면 원문 변경행과 지급행을 함께 제시한다. 변경 이력 미제출을 변경 없음으로 바꾸지 않는다. 제출 이력의 전체성은 별도 확인한다.
- 자금이체 대조군은 자사 계좌 목록과 같은 근거·금액의 반대 은행 입금 및 양쪽 GL 배부를 함께 확인한다. 계좌 이름이 비슷하다는 이유로 자금이체로 분류하지 않는다.

후보는 부정·오류 확정 또는 발생확률이 아니다. 우선순위, 조건, 규칙 버전, 원문 파일/시트/행, 후속 확인 절차를 남긴다. 증거 독립성·수취인 진위·계약 실질은 검증하지 못한다. 동일 생성기의 GL·은행·통제 더미가 일치해도 독립적인 실제 감사증거가 되지 않는다.

## 결과

`현재원장연결`, `현금검사통제`, `계좌잔액대사`, `현금배부표`, `은행장부잔여`, `검토후보`, `규칙미확인`, `현금분석범위`, `현금모집단`을 제공한다. 입력 원문 SHA256과 현재 원장 연결 결과, 규칙 설정·검사 대상 수를 조서용 결과에 보존한다. 수행자·판단·결론·검토자·조정 승인은 비어 있으며 자동 전기하지 않는다.

기본 정상 고정 기대값은 은행 12행·선택 GL 12행·12배부, 입금 2,700,000원·출금 4,350,000원이다. 계정 1000의 기초/기말은 4,200,000/2,550,000원, 무거래 계정 1100은 각각 1,000,000원이다. 합법 자금이체는 별도 현재 원장에 1000→1100의 100,000원 균형 전표를 추가하며 14은행행·14GL행이다.
